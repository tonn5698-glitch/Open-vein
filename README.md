# Vein Miner — Minecraft Forge 26.1.2

A small server-compatible Forge mod for Minecraft 26.1.2.

## Usage

- Hold **Shift** while breaking a block.
- Connected blocks of the same block type are mined automatically.
- Maximum vein size: **64 blocks**.
- The normal block drops are preserved.
- The held tool loses durability for each additional block.
- Creative mode does not trigger Vein Miner.

## Build

Requires **Java 25** and Gradle/Gradle Wrapper.

```text
./gradlew build
```

The Forge target is **Minecraft 26.1.2 / Forge 64.1.3**.
